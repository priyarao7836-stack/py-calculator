# Python Scientific Calculator

##Description
A menu-driven calculator built using Python.

## Features
-Addition
-Subtraction
-Multiplication
-Division
-Percentage
-Square Root
-Power
-Sine
-Cosine
-Tangent
-Logarithm
-Natural Log
-Factorial
-Error Handling

## Technologies Used
-Python 3
-Math Module

## How to Run
   bash
python calculator.py
